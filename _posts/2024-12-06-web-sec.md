## Nmap

### Quick Scan

```bash
nmap $IP
nmap -Pn $IP
nmap --open $IP
```

### Full TCP Enumeration

```bash
nmap -p- -sC -sV --open $IP
nmap -p- -sT -sV -A $IP
```

### Targeted Scanning

```bash
nmap -p80,443 -sC -sV $IP
nmap -p22,21,25,53,80,110,139,143,389,443,445,3389 -sC -sV $IP
```

### Vulnerability Scripts

```bash
nmap -p- --script vuln $IP
```

### HTTP Methods

```bash
nmap -p80,443 --script=http-methods $IP

nmap --script=http-methods \
  --script-args http-methods.url-path='/directory' \
  -p80,443 $IP
```

### Useful NSE Scripts

```bash
nmap --script=banner -p$PORT $IP
nmap --script=http-title -p80,443 $IP
nmap --script=http-enum -p80,443 $IP
nmap --script=smb-enum-shares -p445 $IP
nmap --script=smb-os-discovery -p445 $IP
```

### Save Results

```bash
nmap -p- -sC -sV $IP -oA nmap
```

```bash
dig domain.com

```

### Reverse DNS

```bash
dig -x $IP
```

### Zone Transfer

```bash
dig axfr @ns1.domain.com domain.com
```

### Subdomain Brute Force

```bash
gobuster dns \
  -d domain.com \
  -w /opt/SecLists/Discovery/DNS/subdomains-top1million-110000.txt \
  -t 30
```

> Always verify discovered DNS names resolve to an **in-scope address** before testing them.

# Quick Workflow

```bash
# 1. Full scan
nmap -p- -sC -sV --open $IP -oA nmap

# 2. Technology
whatweb $URL

# 3. Headers
curl -k -I $URL

# 4. Directories
gobuster dir -u $URL \
  -w /opt/SecLists/Discovery/Web-Content/raft-medium-directories.txt \
  -k -t 30

# 5. Files
gobuster dir -u $URL \
  -w /opt/SecLists/Discovery/Web-Content/raft-medium-files.txt \
  -k -t 30

# 6. DNS
dnsrecon -d domain.com

# 7. Subdomains
gobuster dns -d domain.com \
  -w /opt/SecLists/Discovery/DNS/subdomains-top1million-110000.txt

# 8. Historical URLs
gau domain.com | sort -u

# 9. HTTP methods
nmap --script=http-methods -p80,443 $IP

# 10. SSL
nmap --script ssl-enum-ciphers -p443 $IP
```

> **Don't just throw payloads at an application. Understand how it works first.**
